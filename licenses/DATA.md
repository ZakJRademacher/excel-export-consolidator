# Data attribution

Dataset: **Superstore Sales Dataset**, published by **Rohit Sahoo** on Kaggle.

Source: https://www.kaggle.com/datasets/rohitsahoo/sales-forecasting

The source dataset page labels its license **GPL 2**. The included frozen December 2018 partition, its derived demonstration CSVs, expected record IDs, and dataset-derived workbook content retain that source license label. The source license text is included as `GPL-2.0.txt`.

Modifications: selection of eight fields and 300 source records, five export layouts, date and delimiter variations, whitespace/case changes, eight exact repeated copies, one conflicting additional copy, and eight invalid records. The reserved next record supports a refresh demonstration. Detailed changes and a source-partition hash are in `evidence/sample-provenance.json`.

The MIT license for project code and documentation does not relicense the underlying dataset. No ownership of the source dataset or endorsement by its publisher is claimed.
